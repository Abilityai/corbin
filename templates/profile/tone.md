# How I write

The agent copies this file to workspace/profile/tone.md on first run and writes every draft in
this voice. It also learns from the emails you send or approve: when it notices something new
about how you write, it proposes a line here and adds it on your word.

## Voice

Default: plain, direct, friendly. The point in the first sentence. One ask per email.

Example: short sentences, first names, no "I hope this finds you well"

## Length

Default: at most 150 words.

## Greeting and sign-off

Default: "Hi <first name>," and no sign-off beyond the first name.

Example: "Best, Sam"

## Words and phrases I never use

Example: "circle back", "synergy", exclamation marks

# About the person I work for

The agent copies this file to workspace/profile/about-me.md on first run and reads it there.
Fill it in (or tell the agent in chat and it will write it here). A line that starts with
`Example:` is not a setting.

## Name and role

Example: Sam Rivera, founder and CEO

## Organisation

The organisation's name and its mail domain(s), so colleagues can be told from people outside.

Example: Northwind Studio, northwind.example

## My own addresses

Every address I send from, one per line.

Example: sam@northwind.example

## Timezone

Default: UTC.

Example: Europe/Madrid
